# AGENTS.md

- This repository is `pi-monitor`: a lightweight Hyprland (`HEADLESS-1`) + Sunshine + Moonlight Qt orchestration tool for using a Raspberry Pi 5 as a secondary monitor.
- Keep all scripts POSIX/bash-clean (`shellcheck` friendly) and free of personal IP addresses, usernames, or credentials.
- Any personal configuration belongs in `~/.config/pi-monitor/config.env` (never committed).
